# Брикс Шторм 1.12.0 — versionCode 15

## Что нового — текст для пользователей

Уровни теперь открываются по мере прохождения: побеждайте, чтобы открыть следующий лабиринт! Добавили замки и подсказки для закрытых уровней. Ваши звёзды, рекорды и подарки сохраняются. Обновили главное меню и синий фон игрового экрана.

## Комментарий модератору

Регистрация и тестовый аккаунт не нужны. Кампания содержит 300 уровней. При первом запуске доступен первый уровень, каждый следующий открывается после победы на предыдущем. Закрытые уровни отмечены замком. Ранее пройденные уровни доступны повторно, прогресс и подарки при обновлении сохраняются. В версии также обновлены главное меню и синий игровой фон. Интернет, реклама, аналитика, покупки и сбор пользовательских данных не добавлены. Android 8.0 и выше. Приложение подписано прежним сертификатом с сохранением истории подписи.

## Проверка релиза

Package pro.brickstorm.game; minSdk 26; targetSdk 35. Проверяются новая установка, последовательные победы, повторное прохождение, проигрыш и пауза, блокировка прямого запуска закрытого уровня, перезапуск приложения и миграция с временной версии, где вся кампания была открыта. Выбор высокого уровня без победы не даёт доступ. Пройденные ранее вне очереди уровни и их непосредственные следующие сохраняют доступ, но не открывают пропуски между ними. Сохранённые звёзды, рекорды и запас подарков не сбрасываются.

Геометрия всех 300 уровней, физика, синее оформление и иконка версии 1.11.0 сохранены. Прогресс определяется сохранёнными звёздами; отдельного отладочного переключателя открытия всех уровней в APK нет. Проверка движка использует синтетические события победы, не является полным прохождением кампании. APK на телефоне/эмуляторе не запускался.

В RuStore обновление не отправлено. Ранее вход через VK ID был заблокирован политикой доступного браузера; этот вход повторно не выполнялся. APK и тексты готовы для загрузки из кабинета владельца.
