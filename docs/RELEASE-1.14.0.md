# Брикс Шторм 1.14.0 — versionCode 17

Статус: код интеграции подготовлен; реальных ID рекламных блоков ещё нет. Финальная release-сборка с монетизацией и публикация не выполнены. Демонстрационные рекламные блоки доступны только внутренней debug-проверке.

## Что нового — для пользователей

Бонусы за рекламу: заряд ×3, продолжение после поражения и защитная стена. Обычная реклама показывается между уровнями после третьего. Прогресс сохраняется.

## Комментарий модератору — короткий вариант

Добавлена РСЯ: реклама между уровнями после 3-го, интервал 180 с. За просмотр — заряд ×3, продолжение или защитная стена. Вход не нужен.

## Подключение двух блоков

В приложении «Брикс Шторм» в РСЯ нужны два блока: «Межстраничная реклама» и «Реклама с вознаграждением». Для второго название награды «Бонус», количество 1. Один rewarded-блок обслуживает все три вида бонусов; конкретную награду выбирает игра. Нужны ID формата R-M-… именно этой игры, не BusSpark и не ID площадки без номера блока. Заполнить ads.properties или переменные окружения. Release-защита не разрешает пустые или демонстрационные ID.

## Правила

Первый межстраничный показ — на переходе после победы уровня 3. После показа нужны две победы и минимум 180 реальных секунд с закрытия любой рекламы. По таймеру во время полёта шаров показ не начинается. При ошибке/отсутствии объявления можно сразу играть дальше. Награды выдаются исключительно по подтверждению SDK, по одному разу на запрос.

Заряд ×3: до трёх рекламных получений за любые 24 часа, запас максимум три; обычные бесплатные подарки независимы. Сам ×3 используется после запуска шаров один раз за попытку. Продолжение: одна жизнь с сохранением разбитых кирпичей и счёта, один раз за попытку. Стена: 10 секунд активной игры независимо от ×1/×2/×4, один раз за попытку. Ролик/пауза не расходуют время защиты.

## Данные и магазин

Добавлен Yandex Mobile Ads SDK 8.6.0 и сетевые разрешения. Нельзя повторять прежнее заявление «рекламы и передачи данных нет»: SDK обрабатывает технические данные для показов. Геолокация не запрашивается, персонализация и дополнительная App Ad Analytics отчётность отключены. Есть экран информации с ссылкой на политику Яндекса. В карточке магазина потребуется актуально указать наличие рекламы и обработку данных рекламной сетью.
