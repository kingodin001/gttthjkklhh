# Брикс Шторм 1.13.0 — versionCode 16

## Что нового — для пользователей

Новая иконка с оранжевым кирпичным лабиринтом! Добавили более лёгкий первый уровень: шары движутся медленнее, платформа шире, а первые цели проще поразить. Прежние уровни сдвинуты на одну позицию — теперь в игре 301 уровень. Звёзды, рекорды и подарки сохраняются. Уровни открываются по мере прохождения.

## Комментарий модератору

Регистрация и тестовый аккаунт не нужны. В версии заменена иконка и добавлен новый облегчённый первый уровень. Прежний первый стал вторым, остальные сдвинуты следом; прежние 300 раскладок и их сложность сохранены. Кампания теперь содержит 301 уровень с последовательным открытием после победы. Сохранения привязаны к стабильным ID уровней: звёзды, рекорды и подарки при обновлении сохраняются. Интернет, реклама, покупки, аналитика и сбор пользовательских данных не добавлены. Android 8.0 и выше. Прежний сертификат и история подписи сохранены.

## Проверки и публикация

Package pro.brickstorm.game; minSdk 26; targetSdk 35. Проверены структура и окна всех 301 лабиринтов, первое попадание на новом первом уровне без потери жизни за две секунды, совпадение метаданных прежних 300 уровней, их скорости, платформы, seed и начальных шаров; перенос сохранений, подарков и последовательное открытие. Проверки на синтетических состояниях не являются полным прохождением. APK на телефоне/эмуляторе не запускался.

Иконка для карточки магазина: `rustore/icon-512.png`, PNG 512×512. Обновить её нужно также в карточке RuStore; иконка в APK уже заменена во всех плотностях.

Обновление в RuStore не отправлено: ранее вход через VK ID заблокирован политикой доступного браузера, повторного входа не выполнялось. APK, иконка и тексты готовы для загрузки из кабинета владельца.
