# Брикс Шторм 1.1.1

- Полностью удалены «Импульс», заряд энергии, лазерные выстрелы и соответствующие бонусы. Убраны их кнопки, индикаторы и упоминания в подсказках и описании магазина.
- Четыре бонуса: +3 шара, ×3 шаров, расширение платформы, замедление.
- Встроена одобренная иконка с плотным полем мелких разноцветных блоков. Для магазина экспортирован тот же рисунок в PNG 512×512.
- Версия 1.1.1, versionCode 4. Прежний пакет и цепочка подписи сохраняются для обновления существующей установки.

Проверено: автоматические проверки движка, кампании, бонусов, стен и навигации; компиляция Android; состав APK; подпись; выравнивание; manifest и иконки. На физическом устройстве эта версия в данной среде не запускалась. Публикация в RuStore не выполнена.
