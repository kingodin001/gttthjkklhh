# 1.4.0 — маршруты и повторные бонусы

Первые 50 раскладок полностью заменены на маршруты по последним трём концептам. Поле заполнено по всей высоте, в том числе с первого уровня. Проходы, спирали, ступени, двойные обходы и дополнительные стальные направляющие связаны с нижним входом. В каждой из 50 раскладок отличается геометрия, а не только цвета. Сложность управления повышается с номером; количество отрезков и стальных направляющих растёт по главам. Сохранены восемь художественных мозаик — они расположены на уровнях 51–58. Все 58 открыты сразу.

Причина отказа повторного жёлтого ×3 в 1.3.0 — предел 96 шаров: после заполнения пула бонус молча ничего не делал. В 1.4.0 до 512 независимых траекторий; при дальнейшем росте рой объединяется в усиленные группы. Каждый подбор ×3 точно утраивает суммарное число шаров, включая группы, без переполнения целого числа. Группы имеют золотые спутники, усиленный удар по прочным блокам и отдельную подпись в HUD. Общий счётчик отображает весь рой. Голубой +3 также учитывается при заполненном пуле. Потеря группы убирает из роя её шары. Это компромисс для производительности телефона: после 512 траекторий дополнительные шары разделяют траектории внутри групп.

Исправлено начальное положение платформы у боковых входов. Стартовые шары первого уровня направляются к входу с небольшим разлётом. Добавлены блики на гранях блоков. Скорости ×1/×2/×4 и временная нижняя стена сохранены.

Новая геометрия использует отдельные ключи результатов; предыдущие сохранения остаются на устройстве. VersionName 1.4.0, versionCode 7, тот же пакет, Android 8+ и прежняя история подписи.

Проверки: структурная связность 50 открытых маршрутов и доступность разрушаемых клеток; сплошные внешние границы; пролёт шара через каждый вход; короткая проверка стартового запуска; коллизии со сталью; 40 повторных ×3, добавление +3 при полном пуле, усиленный удар группы, таймер стены, скорости, пауза, сохранение и кнопки карты. Полное автоматическое/ручное прохождение кампании не выполнялось. Телефон и эмулятор для этой сборки не использовались.
