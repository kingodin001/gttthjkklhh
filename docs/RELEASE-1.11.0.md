# Брикс Шторм 1.11.0 — versionCode 14

## Что нового для RuStore

Обновили главное меню: синий аркадный стиль, объёмный логотип, яркий лабиринт и большая кнопка «Играть». Добавили экран личного прогресса и информацию о подарках. Игровой экран получил новый синий фон. Звёзды, результаты и запас подарков сохраняются. Все 300 уровней доступны.

## Для проверки

Android 8.0+ (minSdk 26), targetSdk 35; package pro.brickstorm.game. Подписанная release-сборка с прежним сертификатом и историей подписи, устанавливается поверх предыдущей версии с сохранением campaign_v1. Иконка, геометрия всех 300 уровней, физика и условия бонусов сохранены. Интернет, аккаунты, покупки, реклама и аналитика не добавлены.

Автоматические проверки кампании, физики, прогресса, подарков и взаимодействия с новым меню пройдены. Снимки общего с Android рендера просмотрены внутри разработки. Запуск APK на телефоне/эмуляторе и полное прохождение кампании не выполнялись. Обновление в RuStore не отправлено.
