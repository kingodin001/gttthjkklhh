## 1. Размещение страницы

Скачать BrickStorm-website-upload.zip. Внутри только папка brickstorm с HTML, CSS и изображениями; общего app-ads.txt и папки bus-fever в архиве нет.

Войти в свою существующую панель хостинга ISPmanager. Открыть «Сайты» / «WWW-домены», выбрать games-api.vymi.pro и открыть корневой каталог сайта через файловый менеджер. Точный абсолютный путь берётся из настроек этого домена, его нельзя угадывать. Нужен каталог, где уже лежат bus-fever и app-ads.txt.

Загрузить ZIP в этот каталог и распаковать. Результат: brickstorm находится рядом с bus-fever, а не внутри неё. Не создавать второй вложенный brickstorm/brickstorm. Существующие файлы сайта не заменять. PHP, база данных, установка пакетов и изменение конфигурации сервера не нужны. Внешние шрифты, счётчики и регистрация на странице не используются.

Проверить после загрузки:

- https://games-api.vymi.pro/brickstorm/ — главная, иконка, три игровых поля, кнопка RuStore, почта поддержки.
- https://games-api.vymi.pro/brickstorm/privacy/ — политика игры.
- https://games-api.vymi.pro/brickstorm/terms/ — условия использования.
- https://games-api.vymi.pro/app-ads.txt — существующий общий текстовый файл.
- https://games-api.vymi.pro/bus-fever/ — прежняя страница должна продолжать работать.

Если главная возвращает 404, проверить корневой каталог выбранного домена и отсутствие двойной папки. Если картинки отсутствуют — папку brickstorm/assets. Если документы не открываются, проверить наличие index.html внутри privacy и terms. Все адреса должны открываться без входа и без HTTPS-предупреждений.

## 2. Общий app-ads.txt

На момент проверки файл доступен, содержит строку yandex.com, 333513575, DIRECT. Это ID партнёра, а не ID приложения. В РСЯ открыть «Настройки → Общие → app-ads.txt», получить текущий файл и сравнить его со страницей games-api.vymi.pro/app-ads.txt. Если приложение BrickStorm принадлежит этому же партнёрскому аккаунту и строки актуальны, отдельный файл для игры и строка с 20304400 не нужны. Если в текущем аккаунте другие строки, дополнить общий файл недостающими, сохраняя строки Bus Fever. Не заменять его произвольным примером или одним ID приложения.

BrickStorm: ID приложения РСЯ 20304400, interstitial R-M-20304400-1, rewarded R-M-20304400-2. В APK используются реальные блоки. При необходимости обратиться в поддержку РСЯ, если данные разработчика не отображаются; создание дубликата приложения или новых блоков не требуется.

## 3. Проверка APK после размещения документов

Установить BrickStorm-1.14.2.apk поверх предыдущей версии. Убедиться, что прогресс на месте. Настройки → О рекламе и данных → Политика игры: должен открыться опубликованный документ этой игры. Вторая кнопка открывает политику Яндекса. Проверить добровольный ×3 из главного меню и игры: заряд поступает после подтверждённого просмотра, поле и счёт сохраняются. Фактический показ зависит также от готовности приложения в РСЯ и доступности объявления; автоматические проверки не заменяют этот запуск на телефоне.

### Полное описание

Брикс Шторм — арканоид с лабиринтами, цветными блоками и каскадами шаров. Управляй платформой одним пальцем, выбирай угол отскока и направляй шары через узкие проходы в металлических стенах.

Пройди 301 уровень: от первых каскадов до сложных лабиринтов. Разрушай связанные поля кирпичей, находи пути к блокам и открывай следующие уровни по мере прохождения.

В игре:

• металлические стены, узкие входы и отскоки;
• бонусы добавления и умножения всех летящих шаров;
• расширение платформы, замедление и защитная стена;
• скорость ×1, ×2 и ×4;
• звёзды, рекорды и карта уровней;
• бесплатные подарки ×3 с таймером;
• добровольная реклама за заряд ×3, продолжение после поражения или защитную стену;
• сохранение прогресса на устройстве.

Основные уровни доступны без интернета и регистрации. В игре есть реклама между уровнями; для рекламы и рекламных наград нужен интернет. Встроенных покупок нет.
