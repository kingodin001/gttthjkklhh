# Брикс Шторм

Нативный Android-арканоид, версия **1.3.0**, versionCode **6**, package **pro.brickstorm.game**, Android **8.0+** (API 26), target API 35. Release APK использует прежний сертификат и сохранённую историю подписи.

## Кампания

**50 головоломок с отскоками + 8 художественных мозаик**, всего **58** уровней. Все открыты сразу: главное меню → «Уровни», четыре страницы с миниатюрами фактических раскладок. Звёзды и лучшие результаты сохраняются независимо от доступа. Предыдущие результаты классической кампании остаются в прежних ключах настроек; результаты новых раскладок используют отдельный namespace.

Перегородки, смещённые ворота, развилки, открытые крепости, ступенчатые маршруты и квадратные спирали. Художественные уровни: дракон, компас, храм, мотылёк, песочные часы, два карпа, механизм и корона. Рисунок составлен из разрушаемых игровых клеток; это не фон поверх чужой геометрии.

Внешние верхняя и боковые границы сплошные. В нижней стальной стене видны настоящие проёмы. Внутренние щиты имеют открытые обходы. Скорость каждого следующего уровня повышается, ширина платформы уменьшается; после первых уровней добавляются усиленные блоки. Точная субъективная сложность зависит от маршрута и требует игрового балансирования.

## Управление и бонусы

- Веди пальцем, чтобы двигать платформу. Коснись поля, чтобы запустить шар в направлении входа. Место удара о платформу задаёт угол отскока.
- Голубой `+3`: три дополнительных шара над платформой.
- Жёлтый `×3`: каждый летящий шар получает две копии в своём текущем месте, с разлётом по углам. Общий предел — 96 шаров.
- Расширение платформы, замедление и временная нижняя стена. Стена ниже платформы отражает упущенные шары **6 секунд игрового времени**; во время паузы таймер стоит.
- Кнопки скорости `×1`, `×2`, `×4` ускоряют симуляцию целиком без увеличения физического шага.
- «Меню» и «Уровни» приостанавливают текущую партию. «Продолжить» возвращает её до закрытия приложения.

Без сети, аккаунтов, аналитики, рекламы и покупок. Иконка и фон меню сохранены из опубликованной версии. Лазеров и импульса нет.

## Проверки и сборка

`bash tests/run.sh` проверяет все 58 раскладок, доступность блоков при реальном диаметре шара, сплошные внешние стены, реальные пролёты через все входы, отражение стальных стен с обеих сторон и по углам, отсутствие проникновения шаров в сталь, бонусы, паузу, скорости, победу, навигацию и сохранение. Автоматический runtime probe запускает физику всех 58 уровней; это проверка устойчивости, а не полное ручное прохождение.

`tests/RenderCheck.java` проверяет все 58 кнопок выбора на четырёх страницах и экспортирует внутренние снимки общего рендера для проверки вёрстки. Проверочные классы не входят в APK.

`python3 scripts/build-levels.py` воспроизводит авторский каталог и исходный `LevelData.java`. Геометрия задана в коде рецептов, не случайными лабиринтами.

Сборка: Java 17, Android SDK 35, Build Tools 35.0.0; `python3 scripts/assemble-release.py` с `ANDROID_JAR`, `BUILD_TOOLS`, `BRICKSTORM_KEYSTORE`, `BRICKSTORM_KEY_ALIAS`, `BRICKSTORM_KEY_PASSWORD`. Для истории подписи: `BRICKSTORM_PREVIOUS_KEYSTORE`, `BRICKSTORM_PREVIOUS_ALIAS`, `BRICKSTORM_PREVIOUS_PASSWORD`, `BRICKSTORM_LINEAGE`. Материал подписи хранится отдельно и не должен попадать в репозиторий.

Android-компиляция, D8, zipalign, manifest и подпись v2/v3 проверены. На физическом Android-устройстве и в эмуляторе эта сборка в текущей среде не запускалась. Автоматической публикации в RuStore нет.
