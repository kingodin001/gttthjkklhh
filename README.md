# Брикс Шторм

Нативный Android-арканоид **1.8.0**, versionCode **11**, package **pro.brickstorm.game**, Android **8.0+** (API 26), target API 35. Прежний release-сертификат и история подписи сохранены.

## Новая кампания

**200 открытых лабиринтов вместо всей прежней кампании.** Старые 300 раскладок и мозаики не входят в активный каталог. Плотное поле содержит 2327–3297 мелких кирпичей. Тёмные узкие проходы ограждены непрерывными металлическими стенками с обеих сторон. У каждого уровня ровно **1–3 отдельных отверстия к разрушаемым блокам**; остальные границы туннеля закрыты. Верх и боковые стороны поля закрыты.

25 заданных семейств маршрутов включают вложенные контуры, спирали, ступени, вилки, ромбы, восьмёрки, сердца, гребни, треугольники, орбиты и ломаные. Каждое имеет восемь геометрических вариантов: меняются пропорции, длины участков, расположение отверстий, а в поздних вариантах добавляются обходы с новыми поворотами. Это 200 разных геометрий, а не 200 независимых топологических семейств. Соседние уровни чередуют формы. Карта содержит 13 страниц.

Один нижний вход имеет точную ширину **15,5 пикселя** для трёх шаров либо **10,5 пикселя** для двух при диаметре шара 5 пикселей. Коридор вдоль оси имеет не менее трёх клеток ширины. Выходы к кирпичам имеют ширину одной либо трёх клеток; одноклеточный проём 5,75 пикселя пропускает реальный шар. Перед каждым портом выполнена проверка попадания шаром в соседний кирпич. Металлические стены не разбиваются.

Скорость растёт 190…309,4, платформа уменьшается 144…96,24. После уровня 60 добавляется небольшая доля кирпичей с двумя ударами. Структура проверена на связность и достижимость всех кирпичей, что не заменяет прохождение и балансировку на телефоне. Первые уровни не разгоняются до прежней скорости 340.

Новые раскладки имеют отдельные стабильные идентификаторы: результаты прежних уровней не назначаются новым лабиринтам. Исторические данные сохраняются на устройстве, новый каталог начинает с нуля. Результаты новой кампании и выбранный уровень сохраняются. Все 200 уровней доступны сразу.

## Управление и усиления

Веди пальцем, чтобы двигать платформу; коснись поля для запуска. Место удара о платформу задаёт угол отскока. Голубой +3 добавляет три отдельных шара. Жёлтый ×3 утраивает все летящие шары в их текущих позициях. Нет групп или треугольных значков: предел 8192 реальных шара явно показан. Большой рой рисуется пакетно, каждый шар симулируется отдельно.

Сохранены расширение платформы, замедление, временная нижняя стена на шесть секунд игрового времени и скорости ×1/×2/×4. Меню и карта приостанавливают партию. Частиц разрушения, всплывающего комбо, графической полосы прогресса, лазеров и импульса нет. Иконка сохранена. Без сети, аккаунтов, аналитики, рекламы и покупок.

## Проверка и сборка

`python3 scripts/build-levels.py` воспроизводит каталог из `scripts/maze-levels.py`. `bash tests/run.sh` независимо проверяет реальное число окон, непрерывность ограждения, уникальность геометрии, плотность, связность, попадание физическим шаром через каждое окно, входы, отражения, бонусы, паузу, скорости и сохранение. `tests/RenderCheck.java` проверяет все карточки и общий рендер. Проверочные классы не входят в APK. Полного прохождения и запуска на телефоне/эмуляторе в текущей среде не было.

Сборка: Java 17, Android SDK 35; `python3 scripts/assemble-release.py` с `ANDROID_JAR`, `BUILD_TOOLS`, `BRICKSTORM_KEYSTORE`, `BRICKSTORM_KEY_ALIAS`, `BRICKSTORM_KEY_PASSWORD`. Для прежней истории подписи: `BRICKSTORM_PREVIOUS_KEYSTORE`, `BRICKSTORM_PREVIOUS_ALIAS`, `BRICKSTORM_PREVIOUS_PASSWORD`, `BRICKSTORM_LINEAGE`. Ключи хранятся отдельно и не включены в репозиторий. Автоматической публикации в RuStore нет.
