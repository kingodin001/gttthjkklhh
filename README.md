# Брикс Шторм

Нативный Android-арканоид **1.6.0**, versionCode **9**, package **pro.brickstorm.game**, Android **8.0+** (API 26), target API 35. Release APK использует прежний сертификат и историю подписи.

## Уровни

**76 открытых уровней:** 50 маршрутов с отскоками, 18 новых фигурных камер по пользовательскому архиву и восемь художественных мозаик. Новые камеры распределены среди прежних уровней; несколько первых раскладок переставлены. На карте пять страниц с миниатюрами фактической геометрии.

Камеры Р, Т, сердца, звезды, поезда, гребёнок, вложенных замков, углов и других фигур окружены плотным полем кирпичей. У каждой есть реальный вход и выход к внешним блокам. Верх и боковые границы закрыты. Нижние отверстия — **15,5 пикселя** для трёх шаров либо **10,5 пикселя** для двух (диаметр шара 5 пикселей); учитываются точно и в физике, и в рендере. Между раздельными стенами нет однорядных зазоров. Карта соответствий архиву: `docs/REFERENCE-LEVELS-1.6.0.md`.

Звёзды, лучший счёт и выбранный уровень из 1.5.0 сохраняются за той же раскладкой благодаря стабильным идентификаторам. Старые данные не удаляются. Скорость постепенно растёт 190…340, ширина платформы уменьшается 144…84; конкретный баланс разных маршрутов требует игры на устройстве.

## Управление и усиления

Веди пальцем, чтобы двигать платформу; коснись поля для запуска. Место удара о платформу задаёт угол отскока. Голубой +3 добавляет три шара, жёлтый ×3 утраивает весь летящий рой в текущих позициях. До 512 независимых траекторий, дальше — усиленные группы с точным общим счётчиком. Группы сильнее бьют прочные блоки. Есть расширение платформы, замедление, временная нижняя стена на шесть секунд игрового времени и скорости ×1/×2/×4. Меню и карта приостанавливают партию.

Частиц разрушения, всплывающего комбо и графической полосы прогресса нет. Счёт и процент разрушения показаны числами. Иконка сохранена. Без сети, аккаунтов, аналитики, рекламы и покупок. Лазеров и импульса нет.

## Проверка и сборка

`python3 scripts/build-levels.py` воспроизводит каталог; `scripts/reference-levels.py` задаёт новые камеры. `bash tests/run.sh` проверяет структуру уровней, отверстия, столкновения, бонусы, паузу, скорости и сохранение. `tests/RenderCheck.java` проверяет все кнопки карты и общий рендер. Проверочные классы не входят в APK. Полного прохождения и запуска на телефоне/эмуляторе в текущей среде не было.

Сборка: Java 17, Android SDK 35, Build Tools 35.0.0; `python3 scripts/assemble-release.py` с `ANDROID_JAR`, `BUILD_TOOLS`, `BRICKSTORM_KEYSTORE`, `BRICKSTORM_KEY_ALIAS`, `BRICKSTORM_KEY_PASSWORD`. Для истории подписи: `BRICKSTORM_PREVIOUS_KEYSTORE`, `BRICKSTORM_PREVIOUS_ALIAS`, `BRICKSTORM_PREVIOUS_PASSWORD`, `BRICKSTORM_LINEAGE`. Ключи хранятся отдельно и не включаются в исходники.

Android-компиляция, D8, zipalign, manifest и подпись v2/v3 проверены. Автоматической публикации в RuStore нет.
